### Guides
How to run the program?... 
Follow the steps
* step 1: Import the project in your IDE.
* step 2: Change the application.properties according to your system database username and password.
* step 3: Check compiler versions in your systems.
* step 4: Run the program as spring boot application in your IDE.
* step 5: Now your Rest API Surabhi project started on port number 8080 (http://localhost:8080).
* step 6: Now you need to start the angular application

After starting RestAPI run the angular appication using ng serve command in command prompt and if it is successfully compiled, write the http://localhost:4200 url in browser.


Now The fullstack application is started.
